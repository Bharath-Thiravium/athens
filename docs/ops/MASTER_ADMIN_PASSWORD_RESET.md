# Master Admin Password Reset System

## Overview

The master admin password reset system has been enhanced to provide controlled password reset capabilities with superadmin oversight.

## Key Features

1. **One-time reset**: Master admin can reset their password only once after it's been set by superadmin
2. **Superadmin control**: Only superadmin can provide new passwords to master admin
3. **Security tracking**: System tracks whether password was set by superadmin and reset capability status

## Database Fields

Two new fields have been added to the `CustomUser` model:

- `can_reset_password`: Boolean field indicating whether the user can reset their password
- `password_set_by_superadmin`: Boolean field indicating whether the current password was set by superadmin

## API Endpoints

### 1. Master Admin Password Reset
**Endpoint**: `PUT /api/auth/master-admin/reset-password/`
**Authentication**: Required (Master Admin only)

**Request Body**:
```json
{
    "new_password": "your_new_secure_password"
}
```

**Response** (Success):
```json
{
    "success": true,
    "message": "Password reset successfully. You will not be able to reset it again until superadmin provides a new password.",
    "warning": "This was your one-time password reset. Contact superadmin for future password changes."
}
```

**Response** (Error - Already used reset):
```json
{
    "error": "Password reset not allowed. Contact superadmin to reset your password.",
    "message": "You have already reset your password once. Only superadmin can provide a new password."
}
```

### 2. Master Admin Password Status
**Endpoint**: `GET /api/auth/master-admin/password-status/`
**Authentication**: Required (Master Admin only)

**Response**:
```json
{
    "can_reset_password": true,
    "password_set_by_superadmin": true,
    "is_password_reset_required": true,
    "is_autogenerated_password": true,
    "message": "You can reset your password once"
}
```

### 3. Superadmin Reset Master Password
**Endpoint**: `POST /api/auth/superadmin/reset-master-password/`
**Authentication**: Superadmin key required

**Request Body**:
```json
{
    "superadmin_key": "your_superadmin_key",
    "username": "master_admin_username",
    "new_password": "new_secure_password"
}
```

**Response**:
```json
{
    "success": true,
    "message": "Password reset successfully for master admin username. They can now reset it once.",
    "username": "master_admin_username"
}
```

## Management Commands

### Reset Master Admin Password
```bash
python manage.py reset_master_admin_password <username> [--password <password>] [--generate]
```

**Options**:
- `--password`: Specify a custom password
- `--generate`: Generate a secure password automatically

**Example**:
```bash
# Generate a secure password
python manage.py reset_master_admin_password masteradmin --generate

# Set a specific password
python manage.py reset_master_admin_password masteradmin --password "MySecurePassword123!"
```

## Environment Variables

Set the following environment variable for superadmin API access:
```bash
SUPERADMIN_RESET_KEY=your_secure_superadmin_key
```

## Workflow

1. **Initial Setup**: Master admin is created with `can_reset_password=False` and `password_set_by_superadmin=False`
2. **Superadmin Provides Password**: Superadmin uses management command or API to set password, enabling reset capability
3. **Master Admin Resets**: Master admin can reset password once, after which reset capability is disabled
4. **Future Resets**: Only superadmin can provide new passwords and re-enable reset capability

## Security Considerations

1. **Superadmin Key**: Keep the `SUPERADMIN_RESET_KEY` secure and rotate it regularly
2. **Password Strength**: All passwords are validated for strength (minimum 12 characters, mixed case, numbers, special characters)
3. **Audit Logging**: All password reset activities are logged for security auditing
4. **One-time Use**: Each superadmin-provided password can only be reset once by master admin

## Migration

Run the following command to apply the database changes:
```bash
python manage.py migrate authentication
```

This will add the new fields to existing users with default values:
- `can_reset_password=True` (for backward compatibility)
- `password_set_by_superadmin=False`
